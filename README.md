# 지진 지도 만들기 연수 — 안내 페이지

중학교 과학교사 연수 「지구는 지금 어디서 흔들릴까? — 공개 데이터로 만드는 지진·판 경계 탐구 지도」의 단계별 안내 웹페이지입니다.
교사들은 이 페이지를 보며 Google AI Studio → GitHub → Netlify 순서로 **자기 지도 앱**(‘지구는 지금 어디서 흔들릴까?’)을 만들고 배포합니다.
이 저장소는 안내 페이지이며, 교사가 만드는 지도 앱의 코드가 아닙니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm run build      # dist/ 생성
npm run preview    # 빌드 결과 미리보기
npm run check      # 콘텐츠 점검 (단계 구성, 프롬프트 01~09, 자리표시 문구, 용어, 시간 합계)
```

## 배포 (Netlify)

`netlify.toml`에 설정되어 있습니다: Build command `npm run build`, Publish directory `dist`. 환경변수는 없습니다.
`vite.config.js`의 `base: './'` 덕분에 하위 경로나 파일로 열어도 자산 경로가 깨지지 않습니다.

## 콘텐츠 고치기

| 파일 | 내용 |
| --- | --- |
| `src/data/prompts.js` | 실습 프롬프트 01~09, 복구 프롬프트, Netlify 오류 요청 양식 (복사 버튼은 `text`만 복사) |
| `src/data/steps.js` | 0~10단계: 시간, 마치면, 작업 위치, 따라 하기, 정상 결과, 체크리스트, 막혔을 때 |
| `src/data/course.js` | 연수 정보, 용어 설명, 완성 앱 기능, 자료의 한계, 공식 링크 |

본문 표기: `**굵게**`, `` `코드` ``, `[글자](주소)`, `{{용어}}`(용어 첫 등장 위치에 한 번만).
체크 항목 id는 `단계id:블록번호:항목번호`로 만들어지므로, 항목 순서를 바꾸면 그 단계에 저장된 체크 기록이 어긋날 수 있습니다.

## 동작 메모

- 진행 기록·배포 주소는 브라우저 `localStorage`(`eq-guide-v1`)에만 저장됩니다. 서버로 보내지 않고, 다른 기기와 동기화되지 않습니다.
- 저장이 막힌 브라우저에서도 읽기·단계 이동·복사는 동작합니다.
- 단계 주소 공유: `#step-0` ~ `#step-10` 또는 `?step=3`.
- 인쇄 시 모든 단계·프롬프트·도움말이 펼쳐집니다.
- 공식 자료 확인 기준일: 2026-10-14. USGS 피드·판 경계 쿼리 응답은 2026-10-15에 직접 요청해 확인했습니다
  (판 경계: 한 번 응답 1,000건 + `exceededTransferLimit: true`, 전체 1,175건 → 앱에서 페이지 나누기 필요).
